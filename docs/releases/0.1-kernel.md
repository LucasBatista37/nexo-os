## Para publicar (quando o stress de 24 h terminar)

```sh
# 1. Conferir o resultado (deve terminar com PASS e codigo 33):
grep -a "\[STRESS\] PASS duracao=86400s" build/logs/stress-long.log
grep -ac "erros=0" build/logs/stress-long.log     # ~86401 linhas, nenhuma erros=[1-9]
# 2. Copiar o log e escrever docs/progress/<data>-stress-24h.md (modelo: o relatorio de 2 h)
# 3. Marcar o item de 24 h no plano, atualizar ROADMAP (gate F1 ✅) e este arquivo (tirar RASCUNHO)
# 4. make ci   # clone limpo
# 5. git tag -a v0.1-kernel && git push --tags
```

## Conteúdo do marco (já em `main`)

ACPI (MADT/HPET/DMAR), LAPIC/IOAPIC, TSC como relógio monotônico, SMP 4/4 CPUs com dados
por CPU e TLB shootdown, escalonador preemptivo com afinidade, timers de kernel, `IrqLock`,
pânico com backtrace simbolizado (demangler v0 próprio), stress com invariantes.

## Limitações conhecidas

Timer em TCG atrasa em relação ao TSC (documentado em `docs/testing.md`); um só modelo de
máquina (QEMU q35); sem suspensão/energia (Fase 6+).
