O cenário `net` exercita, num único boot e com pacotes reais via slirp: DHCP → ARP → ICMP → DNS →
TCP (saída, entrada, HTTP), IPv6 NS, firewall e a API POSIX. Cobertura de host: parsers e a máquina
de estados TCP no fuzzing semanal do CI.

Pendências da Fase 4: TLS (biblioteca auditada) e armazenamento seguro de certificados (bloco
dedicado, adiado); renovação de DHCP, SLAAC/roteamento IPv6, HTTP/1.1, release `0.4-network`.
