# Código de Conduta

Este projeto adota o [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Resumo: seja respeitoso e construtivo; críticas são sobre código e ideias, nunca sobre pessoas; assédio, discriminação e ataques pessoais não são tolerados; decisões técnicas são registradas em ADRs para que discordâncias tenham um lugar objetivo.

Relatos: ao mantenedor do projeto (até haver equipe, o autor do repositório). Casos serão tratados com confidencialidade e resposta em até 7 dias.
